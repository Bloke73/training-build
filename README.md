# Six Months, 124 Sessions

A documented six-month training build, started at age 53 from a standing start — no pull-ups, no plan.

**Live page:** https://YOURUSERNAME.github.io/training-build/

## What this is

Every training session across six months was generated as its own artifact. This repo holds
the analysis of what those 132 files add up to when you actually measure them — plus the
system that emerged, and the rules that got added each time something broke.

Not a program to copy. A method to steal.

## The numbers

| Metric | Value |
|---|---|
| Documented sessions | 124 |
| Span | ~24 weeks |
| Sessions per week | 5.2 |
| Distinct movements | 251 |
| Total exercise placements | 1,106 |
| Movements that ran exactly once | 106 (42%) |

Largest category by volume: **flexibility at 25%** — which is the most counterintuitive
and most important finding on the page.

## Honest limitations

Counts come from sessions that were **programmed and delivered**, not from a verified
completion log. Exact calendar dates aren't recoverable from the source files, so the
timeline is progression-based rather than date-based. Outdoor activity drove nearly every
programming decision but wasn't logged as structured data during this period — that
starts now.

Full methodology notes are on the page itself.

## What's next

Phase two is logging the outdoor side — BMX climbs, hikes, bouldering, and a snowboard
season — so the actual question can be answered: how do gym volume and outdoor volume
trade off against each other, and is the training supporting the activity or quietly
competing with it?
